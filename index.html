Common questions

Will my code stop working one day?

No. Many QR apps make a code that points at their own short link and forwards people from there, so the code dies when that service stops or asks for money. A Qrisp code holds your content itself. It works without Qrisp, without an internet connection for Wi-Fi and contact codes, and even after you delete the app.

The app says my code "doesn't scan reliably".

Qrisp reads every code back as you design it, and warns you before you print one that phones may struggle with. Usually one of these fixes it:

  • Choose a darker code colour or a lighter background, for more contrast.
  • Try square dots, or remove the logo in the middle.
  • Keep text codes short: the more a code holds, the finer its dots.

Printed codes should be at least 2 cm (about 1 inch) wide, bigger if people scan from a distance.

How do I print a Wi-Fi sign, menu card or labels?

Open a code, tap Print and pick a template: poster, Wi-Fi sign, menu, review card, photo-sharing sign, business cards or a label sheet, in Letter or A4. Print straight to an AirPrint printer, or save a PDF to send to a print shop. Printing is free.

How do batch codes work?

Tap New QR code, then Many at once. Paste a list with one code per line, written as content, name, for example https://example.com/table-1, Table 1, or import a CSV from Numbers, Excel or Google Sheets. A header row such as name,url is fine. You get label sheets to print, a PDF, or a ZIP of SVG files. Batch codes are part of Pro.

Why did the scanner warn about a "redirect service"?

That code does not hold its destination. It sends you to a short link first, and whoever runs that link decides where you end up, and can change it at any time. Qrisp shows you this before anything opens. Tap Show where it really goes to see the real destination.

Is Pro a subscription?

No. Qrisp Pro is a single purchase through the App Store, and it is yours for good. Making codes, colours, saving to Photos, print templates and the code checker are free with no limits. Pro adds logos, gradient themes, dot and corner shapes, frames, SVG export and batch codes, and you can try every Pro style on your own code before you buy. Changed phones? Open Settings in Qrisp to restore your purchase. Refunds are handled by Apple at reportaproblem.apple.com.
